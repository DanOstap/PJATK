## Cele rozwojowe

> Główny kierunek: **Backend Developer** (w ekosystemie `.NET` lub `Java`).

- [x] Opanowanie podstaw obiektowości i tworzenia pierwszych API w `C#` oraz `Java`
- [x] Praca z systemem kontroli wersji `Git` (gałęzie, commity, Pull Requesty)
- [ ] **Architektura aplikacji** - wzorce projektowe, czysty kod (`Clean Code`) i czytelny podział na warstwy
- [ ] **Zaawansowana praca z bazami danych** - optymalizacja zapytań SQL, migracje oraz głebsze poznanie ORM (`Entity Framework Core` / `Hibernate`)
- [ ] **Testowanie oprogramowania** - pisanie testów jednostkowych i integracyjnych (`xUnit` / `JUnit`)
- [ ] **Konteneryzacja** - praktyczne wykorzystanie `Docker` oraz `docker-compose` do uruchamiania środowisk lokalnie
- [ ] **Portfolio i pierwsza praca** - dopracowanie projektów na GitHubie pod kątem pierwszego stażu lub stanowiska *Junior Backend Developer*
