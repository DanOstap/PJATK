# PJATK - Ścieżka rozwoju

Repozytorium utworzone w ramach laboratorium WARP. Zawiera opis dotychczasowego doświadczenia oraz plan dalszego rozwoju.

## 1. O mnie

Jestem studentem informatyki w PJATK. Interesuję się głównie programowaniem backendowym oraz budowaniem aplikacji webowych. Poza zajęciami na uczelni staram się pisać własne mniejsze projekty, żeby lepiej zrozumieć jak działają poszczególne narzędzia w praktyce.

## 2. Dotychczasowe doświadczenie i technologie

Do tej pory miałem okazję pracować z kilkoma językami i technologiami przy okazji projektów uczelnianych oraz własnych:

- C# i platforma .NET - pisanie aplikacji konsolowych i backendowych, praca z kolekcjami, obiektowość, podstawy architektury.
- Java i Spring Boot - tworzenie prostych REST API, konfiguracja Spring Security, mapowanie encji (JPA/Hibernate) oraz obsługa autoryzacji.
- Bazy danych - podstawy SQL, praca z relacyjnymi bazami danych (m.in. PostgreSQL oraz baza H2 wykorzystywana lokalnie podczas testów).
- Frontend - podstawowa znajomość HTML, CSS, JavaScript oraz Reacta (w stopniu pozwalającym na spięcie prostego interfejsu z backendem).
- Narzędzia - praca z systemem kontroli wersji Git i platformą GitHub, środowiska Rider oraz IntelliJ IDEA, podstawy Dockera.

## 3. Cele rozwojowe

Moim głównym celem jest rozwój w kierunku Backend Developera (w ekosystemie .NET lub Java). W najbliższym czasie chcę skupić się na kilku konkretnych obszarach:

1. Pogłębienie wiedzy z zakresu architektury aplikacji backendowych (wzorce projektowe, czysty kod, podział na warstwy).
2. Lepsze opanowanie pracy z bazami danych - optymalizacja zapytań SQL, migracje oraz ORM (Entity Framework Core / Hibernate).
3. Pisanie testów jednostkowych i integracyjnych, których często brakowało w moich pierwszych projektach.
4. Praktyczne wykorzystanie konteneryzacji (Docker, docker-compose) do uruchamiania całych środowisk lokalnie.
5. Przygotowanie portfolio projektów na GitHubie pod kątem pierwszego stażu lub pracy jako Junior Backend Developer.

## 4. Plan działania na najbliższe semestry

- Dokończenie i uporządkowanie obecnych projektów w repozytoriach (dodanie dokumentacji, poprawa struktury kodu).
- Stworzenie jednego większego projektu fullstackowego z naciskiem na backend (autoryzacja JWT, baza PostgreSQL w Dockerze, testy).
- Regularna praca z Gitem z podziałem na gałęzie i Pull Requesty zamiast wrzucania wszystkiego bezpośrednio na gałąź główną.
- Nauka algorytmów i struktur danych potrzebnych na rozmowach rekrutacyjnych.
