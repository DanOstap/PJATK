# PJATK - Ścieżka rozwoju

Repozytorium utworzone w ramach laboratorium WARP. Zawiera opis dotychczasowego doświadczenia oraz plan dalszego rozwoju.

## 1. O mnie

Jestem studentem informatyki w PJATK. Interesuję się głównie programowaniem backendowym oraz budowaniem aplikacji webowych. Poza zajęciami na uczelni staram się pisać własne mniejsze projekty, żeby lepiej zrozumieć jak działają poszczególne narzędzia w praktyce.

## 2. Dotychczasowe doświadczenie i technologie

Do tej pory miałem okazję pracować z kilkoma językami i technologiami przy okazji projektów uczelnianych oraz własnych:

- C# i platforma .NET - pisanie aplikacji konsolowych i backendowych, praca z kolekcjami, obiektowość, podstawy architektury.
- Java i Spring Boot - tworzenie prostych REST API, konfiguracja Spring Security, mapowanie encji (JPA/Hibernate) oraz obsługa autoryzacji.
- Bazy danych - podstawy SQL, praca z relacyjnymi bazami danych (m.in. PostgreSQL oraz baza H2 wykorzystywana lokalnie podczas testów).
- Frontend - podstawowa znajomość HTML, CSS, JavaScript oraz Reacta (w stopniu pozwalającym na spięcie prostego interfejsu z backendem).
- Narzędzia - praca z systemem kontroli wersji Git i platformą GitHub, środowiska Rider oraz IntelliJ IDEA, podstawy Dockera.
